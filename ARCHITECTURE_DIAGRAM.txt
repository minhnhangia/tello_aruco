KEY DESIGN PATTERNS
═══════════════════════════════════════════════════════════════════════════════

1. VALIDATION-APPLICATION SEPARATION
   ┌──────────────┐   Valid    ┌──────────────┐
   │  Validate    │ ─────────► │   Apply      │
   │  (Pre-check) │            │  (Post-set)  │
   └──────┬───────┘            └──────────────┘
          │ Invalid
          └────────► Reject + Error Message
   
   ✓ System never enters invalid state
   ✓ Clear error feedback to user

2. ATOMIC UPDATE
   dictionary_ (cv::Ptr) ──┬──► Old Dictionary
                           │
   [Parameter Change]      │
                           │
   dictionary_ (cv::Ptr) ──┴──► New Dictionary
   
   ✓ Single pointer assignment (atomic)
   ✓ No intermediate invalid state
   ✓ Thread-safe with cv::Ptr reference counting

3. ZERO DOWNTIME
   Frame 1: detectMarkers(dict_A) ───► Detections
                                    ↓
                        [Parameter Change: dict_A → dict_B]
                                    ↓
   Frame 2: detectMarkers(dict_B) ───► Detections
   
   ✓ Change happens BETWEEN frames
   ✓ No frame skipped or lost
   ✓ Detection continues uninterrupted
